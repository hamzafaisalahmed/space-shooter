# Space Shooter

A 2D space shooter game built with C++ and SFML.

## Dependencies
- SFML 2.6
- CMake 3.21+
- MinGW-w64 (ucrt64) — install SFML via `pacman -S mingw-w64-ucrt-x86_64-sfml`

## Features
- 3 levels 
- Boss encounters
- Pause/Resume functionality
- Particle effects and animations
- Level select screen

## Controls
- **Arrow Keys**: Move
- **Space/Enter**: Start/Select
- **P/Esc**: Pause
- **Mouse**: Select levels
